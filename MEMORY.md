# Hikvision Doorbell Lite Decisions

- 2026-10-06: offline-only implementation authorized for DS-KV6113-WPE1(B) and DS-KH6320-WTE1. Keep ring events, call state, outdoor unlock, availability/recovery and Stop ringing. No deployment, real device commands, HA changes, or Frigate changes authorized.
- Based on upstream `8f8b97c6b5731e9979eee28d011db6b860b826e1`. Original source remains in Git and upstream. Do not silently synchronize from upstream over the reduced implementation.
- One Paho client and native HA MQTT discovery; no entity framework, stdin command path, audio/video or scene/alarm functions. One validated JSON config, with optional Supervisor MQTT lookup. Runtime direct dependencies: Paho, Pydantic, Loguru.
- Preserve native SDK libraries and ABI definitions. SDK request URL length is the actual buffer length; request/login timeouts are bounded. Copy callback values before returning to the vendor; never enqueue borrowed pointers.
- Commands are non-retained, connection-epoch scoped, expire after three seconds and are not retried after an ambiguous error. Unlock is outdoor-only. Stop ringing sends reject, never answer/hang-up, and requires a fresh ringing status.
- New slug and unique IDs are intentional. No automatic cleanup or migration of upstream entities. Keep the previous add-on disabled but available for rollback during an eventual separately approved pilot.
- Exact firmware model strings, event delivery, call transitions, physical unlock, Stop ringing and recovery remain unverified on hardware. Unsupported call-status polling yields event-only state, with unknown after 120 seconds; it cannot authorize Stop ringing.
- Offline pytest and both architecture image/SDK checks are the release preparation gates, not hardware acceptance. SDK network-interface warnings are expected in network-disabled smoke tests.
- Publishing remains disabled. Upstream project-wide and vendor SDK redistribution terms must be clarified before distribution; the nested example license does not cover the project.
- Final offline verification, 2026-10-06: 64 pytest checks pass with sockets and native-library loads blocked; focused flake8, Compose parsing and editor diagnostics pass. Local amd64 and emulated aarch64 images build and pass SDK initialization, callback registration, real Paho construction and cleanup with `--network none`. No device credentials or commands used. Active Python source is 5,523 -> 1,569 lines (71.6% reduction); requirements are 29 -> 3 direct runtime entries. Local image tags: `hikvision-doorbell-lite:offline` and `hikvision-doorbell-lite:offline-arm64`. Public PyPI wheel TLS failed on this workstation; the existing public package mirror succeeded without disabling TLS.
